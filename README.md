# 🎭 AGY Roleplay Studio (Android 16 Standalone + Git Auto-Update)

Мобильное приложение для текстовых ролевых игр на базе **Google Antigravity (AGY)** с полностью автономным сервером внутри APK (`LocalBackendServer` + `SQLite` + `workspace/`) и системой автоматического обновления напрямую через Git.

## ✨ Основные возможности
- **Автономная работа на смартфоне (Android 16, API 35/36)**: встроенный Java-сервер и база данных SQLite работают прямо внутри APK без необходимости запускать ПК.
- **Автообновление через Git (OTA + APK)**:
  - При каждом входе приложение автоматически проверяет `version.json` и свежие коммиты в Git-репозитории и показывает всплывающий баннер обновления.
  - На вкладке **«🔄 Версии»** можно просматривать историю всех релизов и коммитов Git и обновляться в один клик (мгновенное OTA-обновление без потери базы чатов или скачивание полного `agy-roleplay-android16.apk`).
- **Вход через Project ID**: поддержка Google Antigravity Project ID.
- **Чистый выбор моделей и отдельный Effort**:
  - 7 базовых моделей (`Gemini 4 Argon`, `Gemini 3.1 Pro`, `Gemini 3 Flash`, `Claude Opus 4.6`, `Claude Opus 4.5`, `Claude Sonnet 4.6`, `GPT-OSS 120B`).
  - Отдельный переключатель глубины рассуждений **Effort** (`Low`, `Medium`, `High`, `Max`).
- **Персонажи и Персоны через файлы**: карточки хранятся в `workspace/characters/*.md` и `workspace/personas/*.md`, поддерживают выбор аватаров с телефона и настройку начального сообщения.
- **Файловый менеджер `workspace/`**: создание, редактирование и удаление папок и текстовых файлов прямо в приложении.

## 📦 Сборка APK
```powershell
powershell -ExecutionPolicy Bypass -File .\android\build-apk.ps1
```
Готовый установщик сохраняется в корне репозитория: `agy-roleplay-android16.apk`.
