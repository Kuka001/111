Android build of proot used by the on-device Claude Code runtime
================================================================

These files are unmodified binaries from the Termux package repository
(https://packages.termux.dev/apt/termux-main/, aarch64). They are shipped
inside the APK because Android cannot decompress the repository's .deb/xz
packages without extra native code.
